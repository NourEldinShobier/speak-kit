## (h) Motion rules (page 42669: M1 42670, M2 42783, M3 43048, M4 43116)

Principle (M1): "enter fast and settle, leave faster than you arrived. Everything respects reduce motion." Distances 4-12 px; nothing animates longer than 333 ms except loops tied to live work.
- `motion/instant` 83 ms (hover fills, pressed, text crossfade); `fast` 167 ms decelerate (0,0,0,1) (menus, popovers, chips, segmented thumb); `normal` 250 ms decelerate (panels, sheets, toasts, expanding sections); `slow` 333 ms point-to-point (0.55,0.55,0,1) (docking, resizing, progress bars); `exit` 120 ms accelerate (0.3,0,1,1); `spring` stiffness 420 damping 34 (voice pill, mobile sheets); `loop-breathe` 1600 ms ease-in-out infinite (agent glow, live dots); `loop-spin` 800 ms linear; `shimmer` 1200 ms linear; `stagger` 40 ms per item, max 6. Reduce motion: fades only (83 ms), loops stop, glow becomes a static border.
- M2 lists 19 elements with trigger, animation, duration, easing and reduce-motion fallback. Reusable for us: panel slide 24 px + fade (normal, point-to-point; exit); floating window scale 0.96->1 + rise 8 px (fast; exit faster); hover card scale 0.96->1 after 300 ms hover, 100 ms leave; segmented thumb slides (fast); toast slides 16 px from top-right, text crossfades on progress, hides after 6 s unless it needs you; approval card orange border pulses twice (600 ms); pill grows with spring, content fades in after 60% width, shrinks to a dot after 4 s of silence and fades to 55%; dot-matrix level meter 0-2 dots per column, smoothed 80 ms at 60 fps (reduce motion: one steady dot row).
- M4 storyboard: 36 px tall pill, width follows content with the spring, stop button never moves once shown. Timeline labels in mono ("+180 ms", "4 s quiet").

## (j) Naming and organization

- **Pages** by surface. **Sections**: `N - Title - what it covers` (e.g. `9 - Living on the desktop - tray, menu bar, notifications, updates, quitting`), numbered across a page (desktop page has 15, web 14), section 1140 px tall, width fits its frames (6260, 7800, 13960...), frames start at x=100, y=140, 100 px gaps (1540 pitch).
- **Frames**: `<ID> - Title - description`, 1440x900, board frames wider (2960x669 for error boards, 2160x755 for empty states) and shorter. ID prefixes encode area: `X1-X16` desktop shell/onboarding, `TR/NO/UP/QT` tray, notifications, updates, quit; `SD1-SD9` desktop settings, `ST1-ST8` web settings; `ES/EM` edge and empty states; `EH/CP/EX` extensions hub, palette, install; `LM` light mode; `BR` browsing; `D1-D6`, `V1-V6`, `M1-M4`, `F1-F14` on the browser/motion/feature pages; `MW/TB` mobile and tablet; `L<n>-light` / `L<n>` web screens; a suffix `m` or `b` marks a variant (`X11m` macOS, `D1b` empty).
- Descriptions are in the frame name after an em dash and say the **rule or behavior**, not only the content ("Updates - never forced, installs when you quit, or restart now"; "Quit while work is running - say what stops and when it resumes"). Annotation cards ("Tray rules", "Notification rules", "Breakpoint rules") sit inside the frame, bottom left, 420x140, bullets 11 px.
- Labels: `SUPERSEDED by ...` and `LATER (v2)` are used in names and as `v2` pills in the settings nav. Research page holds feature-map and competitor boards (11 frames). Foundations page = icon set only (Tabler outline, stroke 1.5, 253 icons).
- Each flow ships: normal states, edge/error board, empty state board, 3-4 light-mode frames, and a component board next to it.
