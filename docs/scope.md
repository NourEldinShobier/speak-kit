# Scope: every design frame that was "Not captured"

Source list: the "Not captured" table of `visual-fidelity.md` (generated by the visual harness at v0.1.0). Each frame is now either **implemented** or has an `out of scope: <reason>` line.

How to read it:

- **implemented** means the product has the screen or behaviour and a test (unit, Electron or Playwright) covers it. It does not mean the visual harness has a screenshot diff for it: the harness (`code/e2e/visual`) was not extended for the library, reader, export, tray panel, mini player, engines and system pages, so those frames stay "not captured" in `visual-fidelity.md` even though they exist. Native surfaces (tray menu, OS toasts, context menu) cannot be screenshotted at all.
- **implemented, unverified on hardware** means the code path exists and is tested against a fake, but it needs a machine this repository was not built on (Chatterbox needs Python 3.10 to 3.12 and an NVIDIA GPU; this machine has Python 3.13 and 3.14).
- Frames that are boards, foundations or superseded versions are documentation, not screens.

## Out of scope

| Frames | out of scope: reason |
|---|---|
| G3 G4 G5 G6 G7 G15 G11 G14 (voice cloning screens: choose reference, recording, analyzing, name and test, bad reference, review take, voice style, cloning unavailable) | out of scope: the cloning API, the clip checks and the Chatterbox sidecar are built and tested (`POST /v1/voices/clone`), but the screens are not, because Chatterbox could not be run on this machine and a recording UI cannot be verified without the real engine. Next release. |
| K6 (Microphone permission) | out of scope: needs recording, which comes with the cloning screens |
| G2 (Voice detail drawer), G13 (Voices list view) | out of scope: the Voices page lists voices with a preview button; a drawer and a second layout add no capability |
| F14 (Reader voice panel dock) | out of scope: voice and speed are popovers in the player bar; the dock layout is a different arrangement of the same controls |
| Bookmarks in F6 | out of scope: the outline panel lists headings only |
| H3 (Pronunciation dictionary) | out of scope: no engine API for custom pronunciations exists; kokoro-js and Chatterbox take text only |
| H17 (Search settings) | out of scope: the title bar search opens the command palette (L2, L3), which finds every settings page |
| I13 (Mini player storyboard: shrink to a dot) | out of scope: the mini player closes itself 6 s after finishing |
| I1 I2 I7 I8, D1 to D7, D9, B21 | superseded by newer frames (I10, I11, W1 to W5, B4) |
| K3 (Low disk space), K4 (Model checksum failed), K10 (Repairing model) | out of scope: no disk check or model hash is computed; a failed download shows the Retry banner (W3b) |
| K5 (Extension out of date, in the desktop app) | out of scope: the extension's popup shows "Update needed" on a version mismatch (A18); the desktop app does not check the extension |
| K8 (Offline notice) | out of scope: everything runs locally; only the model download needs a network and shows its own error |
| C14 (Open SpeakKit link flow) | out of scope: handed to the OS protocol handler, no SpeakKit screen exists |
| C15 (Per-site permissions) | out of scope: the content script is declared for all http, https and file pages; the only host permissions are localhost |
| C16 (Shortcut conflict in options) | out of scope: needs Chrome's own `chrome://extensions/shortcuts` state, which extensions cannot read |
| C17 (Breakpoint rules) | a rule card, not a screen; the collapsed layout is captured as C18 |
| W0 (First launch splash) | out of scope: the app opens straight on Welcome (W1) |
| R1 to R6, Q1 to Q5, MO1 to MO3, K12, E17, O1 (and their light twins) | boards of research, foundations, motion and edge-state overviews, not product screens |

## Also not done (from the build reports, not design frames)

- The packaged server does not bundle `chatterbox_sidecar.py`; a packaged app must point `SPEAKKIT_CHATTERBOX_SCRIPT` at it.
- MP3 for exports is encoded in the desktop app, not in the server.
