# Lessons

Applies to: Speak Kit, started 2026-11-01. Rule id D13 in `docs/engineering/ostio-practices.md`.

## Graduation order
A lesson is a note about something that went wrong or surprised us. It becomes a rule only after three or more tasks hit it and a test or replay shows the fix works. It then moves, in this order, to the first place that can enforce it:
1. a tool (lint rule, ratchet, check script in `code/scripts/`);
2. a test;
3. a skill or a section of `docs/architecture.md`;
4. `code/CLAUDE.md`, only when nothing else can express it.

Lessons about an external tool carry the version they apply to. A lesson that graduates is deleted from this file with a pointer to where it went.
