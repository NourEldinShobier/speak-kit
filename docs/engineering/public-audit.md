# Public repository audit

Audit of everything tracked in git before the repository goes public. Date 2026-11-01, against `origin/main` (39 commits, 1844 tracked files).

How it was checked: tracked file listing and sizes (`git ls-tree -r -l`), regex scans of the tree for key, token and password patterns, scans for personal paths and e-mail addresses, history scans (`git log -S"PRIVATE KEY"`, added `.env`/`.pem`/`.pfx`/credential files), and a look at every binary type.

## Result

No credentials, keys, tokens or `.env` files in the tree or in history. One item removed (item 2). The rest is kept or listed for the owners of those paths.
