# Privacy

Applies to: Speak Kit v0.3.0, written 2026-11-01 from a read of the source and `docs/decisions/0001-stack.md`. Speak Kit reads text aloud on your own computer. The text you read, the documents in your library and the audio never leave the machine.

## What stays on the machine
- Page text sent by the extension goes to the app on `127.0.0.1` (loopback), never to the internet.
- Speech is generated by local models (Kokoro in a child process; Chatterbox in a local Python environment).
- The library, settings, cloned voice clips, exports and logs are files in the app's data directory (Electron `userData`).
- There is no analytics, no crash reporting service, no account and no telemetry.

## Network calls the app makes
Each row is a call that exists in the code today. A new row needs an update to this page (`code/scripts/check-network.mjs`, work package 1, fails when a new host appears in runtime code outside its allow-list).

| Call | When | Where | What is sent | Can the user stop it |
|---|---|---|---|---|
| Update check | Packaged build only, 1 time shortly after start, then daily | GitHub Releases for `NourEldinShobier/speak-kit` (electron-updater) | A normal HTTPS request for `latest.yml` from the release; your IP address and the app version reach GitHub | Yes: the "check for updates" setting. Nothing downloads without your click ("Restart now" or "Install when I quit"). |
| Kokoro model download | First use, if the model files are not present | Hugging Face (through `kokoro-js` / `@huggingface/transformers`) | HTTPS requests for the model files; IP address reaches Hugging Face | Cancel the download; the engine stays unavailable |
| Chatterbox install | Only when you press Install on the optional engine | Python package index through uv or pip, `download.pytorch.org` (torch wheels), Hugging Face (model weights, five files) | Package and file requests; IP address reaches those hosts | Yes: it never starts by itself; Cancel stops it |
| OCR language data | First time you accept OCR on a scanned PDF | `cdn.jsdelivr.net` (the only host the renderer's Content-Security-Policy allows besides itself) | HTTPS request for the language file; IP address reaches the CDN | Yes: OCR runs only after you agree |
| Web address import | When you add a web address to the library | The host you typed | An HTTPS GET for that address. Only public addresses are fetched: loopback, private, link-local and shared-address ranges are refused, at most 5 redirects, body capped at 8 MB | Yes: only on your action |
| Opening links | When you click Download, Learn more or Help in the extension | `speakkit.app` pages in your browser | Nothing from Speak Kit; the browser opens the page | Yes |

## What reaches the local server
The loopback server accepts requests with the pairing token from the extension or the desktop app only. Web pages cannot call it (Origin and Host checks, `docs/threat-model.md`). Request bodies contain the sentences to read, a voice id and a speed.

## Stored data
| Data | Where | Notes |
|---|---|---|
| Pairing token | `<dataDir>/token` and `chrome.storage.local` | Accepted risk, ADR 0006 |
| Settings | `config.json`, `chrome.storage.sync` | Browser sync copies extension settings through your browser account if you turned browser sync on; that is the browser's feature |
| Library | `library/library.json` plus one file per document body | Local only; delete the folder to remove it |
| Cloned voice clips | `<dataDir>` engine folder | Kept until you delete the voice; consent is asked before cloning |
| Logs | `<userData>/logs/main.log` (1 MB, one old file) | Plain text; may contain file names and error messages. Hashing paths at `info` level is planned (refactor plan G07) |

## Not verified
- The call list comes from reading source and the stack record, not from a packet capture of a running packaged app. A capture on the dev machine would confirm there are no other hosts.
- Whether `kokoro-js` contacts other hosts than Hugging Face for model files.
